# ADR-0034：分支列表的多选与目录批量删除

状态：Accepted

## Context

分支列表把 ref 按 `/` 折成目录（`feature/pay/a` 落在 `feature/pay` 下），删除一次只作用于一行。实际使用里清理一批已合并的 `feature/*` 时，只能一个一个右键、确认、删掉；目录行本身也没有任何菜单。

要求：支持多选后右键删除；支持选中/右键一个目录，删除其下所有分支。

约束：

- 行单击的现有含义是「把历史过滤到这个 ref」，不能改成选择，否则过滤要另找入口；
- 删除是不可逆写操作，现有的单条删除已经有两阶段安全流程（安全 `-d`，未合并才允许勾选强制 `-D`），批量必须复用同一套安全语义；
- 右键菜单的目标值在手势时捕获，菜单项不改选中/过滤（ADR-0028）；
- 列表每次快照重建，选择必须按名字而不是对象身份，并在分支消失后修剪。

备选：复选模式（像变更列表）、选择模式开关、Ctrl/⌘+Shift 手势。前两者要么挤压行宽、要么多一个模式状态；变更列表已有「组选/批量」的先例，但分支行更密，最终选手势。

## Decision

- **选择手势（A1）**：Ctrl/⌘+单击切换一行，Shift+单击按**当前可见行顺序**扩展范围（从上次选择锚点起，双向），普通单击仍是历史过滤。Shift 的顺序在点击时从本面板自己的列表 DOM 读取，折叠的目录自然不参与。
- **选择状态**：`OverviewTab` 持有 `readonly string[]`（本地分支名）+ 锚点。新快照到达时按当前本地分支名集合修剪（`pruneBranchSelection`）；仓库切换、批量删除完成后清空。选择只覆盖**本地分支**：远程行与标签行不参与（它们有各自的删除路径，且远程删除是网络写）。
- **目录行**：本地目录行获得菜单与修饰键手势。菜单值携带 `dir` + `dirBranches`（该目录下所有本地分支，**含同名 `self` 分支**，与是否展开无关，排除当前分支）；菜单提供「选择此目录下的分支」与「删除此目录下的 N 个分支」。Ctrl/⌘+单击目录行等价于选择其全部本地分支（已全选则取消）。
- **菜单**：右键落在多选中的一行时，删除项变成「删除选中的 N 个分支」；右键不在选中集合里的行仍是单条删除；右键不改变选择。当前分支永远不进批量集合（选中里若残留也会被剔除）。
- **执行**：批量走客户端顺序调用现有的 `branch-delete`（每次 host 都重新校验存在/合并/worktree 占用），整个批次共享一个 busy 窗口（`runRemoteBatch`）。先对全部目标跑安全 `-d`；只有被拒绝为 `branch-unmerged` 的子集进入第二阶段，弹「强制删除 M 个」并要求勾选确认，只对这批跑 `-D`。其余失败（已被其它 worktree 检出、已不存在等）与成功数一起汇总到状态栏 warn 槽，弹窗关闭并刷新一次。
- **确认**：一个弹窗列出目标（最多 20 个名字，其余折叠为计数）；一次最多 200 个分支，超过时确认按钮锁死并显示原因。
- 不新增 host 端点、不改 wire 契约：批量只是客户端把单条写组合起来，旧 host 的能力位 `branchDelete` 缺失时这些入口整体不出现。

## Consequences

- 清理成批 `feature/*` 从 N 次「右键→确认」变成 1 次确认；目录行直接覆盖折叠在内的全部分支，不依赖展开。
- 代价：批量删除放大了误删后果，安全网只有清单 + 当前分支剔除 + 未合并的二次勾选 + 200 上限；不做撤销（git reflog 仍是唯一退路，文案里写明）。
- 选择只覆盖本地分支；远程分支/标签的批量删除没有实现（远程删除每条一次 `git push --delete`，需要单独的确认与网络失败模型）。
- 选择依赖行顺序读取 DOM 来做 Shift 范围：若将来列表改为虚拟化，范围选择需要改为基于列表模型计算。
